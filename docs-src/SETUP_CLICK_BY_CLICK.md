# راه‌اندازی کامل دُنگ با نوتیفیکیشن — کلیک‌به‌کلیک (بدون دانش فنی)

کل کار ۳ بخش است و روی هم **حدود ۲۰ دقیقه** وقت می‌برد. هیچ کدی لازم نیست بنویسی؛ فقط کپی/پیست.

| بخش | زمان | نتیجه |
|---|---|---|
| A. سرور با یک دستور | ۵ دقیقه (+ ۳ دقیقه صبر) | سایتت بالا می‌آید: `https://دامنه` |
| B. Firebase (۲ فایل دانلود) | ۷ دقیقه | نوتیفیکیشن روی گوشی اعضا |
| C. یک Secret در GitHub | ۲ دقیقه | اپ اندروید با نوتیف ساخته می‌شود |

---

## قبل از شروع: ۲ چیز لازم داری

### ۱) یک سرور مجازی (VPS)
یک لینوکس Ubuntu 22.04 یا 24.04 با حداقل ۱GB رم. بعد از خرید، سه چیز به تو می‌دهند: **IP**، کاربر `root`، و **رمز** (یا کلید SSH).

> ⚠️ **مهم برای نوتیفیکیشن:** سرور را **خارج از ایران** بگیر (مثلاً آلمان/هلند/ترکیه). Google اجازهٔ ارسال نوتیف (FCM) از IP ایران را نمی‌دهد. گوشی کاربران داخل ایران مشکلی برای *دریافت* ندارند.
>
> گزینه‌های ارزان (حدود ۴ تا ۶ دلار/یورو در ماه): Hetzner، Contabo، DigitalOcean، Vultr. اگر کارت بین‌المللی نداری، فروشنده‌های ایرانیِ «سرور مجازی خارج» (با جستجوی همین عبارت) همین سرورها را ریالی می‌فروشند.

### ۲) یک دامنه (اختیاری ولی خیلی توصیه می‌شود)
بدون دامنه هم کار می‌کند (با IP)، ولی برای **HTTPS، دوربین و PWA** دامنه لازم است. یک ساب‌دامنه هم کافی است، مثلاً `dong.example.ir`.
در پنل دامنه یک رکورد **A** بساز: نام `dong` → مقدار = IP سرور. (۵ تا ۳۰ دقیقه طول می‌کشد فعال شود.)

---

## بخش A — نصب سرور با یک دستور

1. به سرور وصل شو:
   - **ویندوز:** برنامهٔ رایگان [PuTTY](https://www.putty.org) را باز کن → در Host Name آی‌پی سرور را بزن → Open → `login as: root` → رمز را بزن (موقع تایپ رمز چیزی نشان داده نمی‌شود، طبیعی است).
   - **مک/لینوکس/اندروید (Termux):** `ssh root@IP-سرور`
2. این خط را کپی کن، در پنجرهٔ سیاه **راست‌کلیک** کن (پیست می‌شود) و Enter بزن:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/soheilxcoder/dong/main/scripts/install.sh | bash
   ```
3. دو سؤال می‌پرسد:
   - **دامنه:** مثلاً `dong.example.ir` (اگر نداری فقط Enter بزن)
   - **ایمیل:** برای گواهی HTTPS رایگان (هر ایمیلی)
4. ۳ تا ۵ دقیقه صبر کن. آخرش می‌نویسد:
   ```
   ✔ دُنگ نصب شد!  آدرس:  https://dong.example.ir/
   ```
5. آدرس را در مرورگر باز کن → صفحهٔ ورود دُنگ ✅

از این به بعد این دستورها را روی سرور داری:
`dong-update` (به‌روزرسانی)، `dong-backup` (بک‌آپ دستی؛ شبانه خودکار هم هست)، `dong-firebase` (بخش B)، `journalctl -u dong -f` (لاگ).

## بخش B — Firebase: نوتیفیکیشن روی گوشی اعضا

نتیجهٔ این بخش **۲ فایل** است:
- `google-services.json` ← برای ساخت اپ (بخش C)
- `xxx-firebase-adminsdk-xxx.json` ← برای سرور

### B1) ساخت پروژه (۲ دقیقه)
1. برو به **<https://console.firebase.google.com>** و با اکانت گوگلت وارد شو.
2. روی **Create a project** (یا **Add project**) کلیک کن.
3. اسم بنویس: `dong` → **Continue**.
4. صفحهٔ Google Analytics: کلید **Enable Google Analytics** را **خاموش** کن → **Create project**.
5. ۳۰ ثانیه صبر → **Continue**.

### B2) اپ اندروید و فایل `google-services.json` (۲ دقیقه)
1. وسط صفحهٔ Project Overview، روی آیکون **Android** (روبات سبز، زیر عنوان *Get started by adding Firebase to your app*) کلیک کن.
2. در **Android package name** دقیقاً این را بنویس: `ir.dong.app`
3. بقیه را خالی بگذار → **Register app**.
4. دکمهٔ **Download google-services.json** → فایل دانلود می‌شود. ✅ **فایل ۱**
5. **Next** → **Next** → **Continue to console** (کدهای Gradle که نشان می‌دهد را نادیده بگیر؛ در اپ از قبل انجام شده).

### B3) کلید سرور (۲ دقیقه)
1. بالا-چپ، کنار **Project Overview** روی **چرخ‌دنده ⚙** کلیک کن → **Project settings**.
2. تب **Service accounts** (بالای صفحه).
3. پایین صفحه دکمهٔ **Generate new private key** → در پنجره **Generate key**.
4. فایلی مثل `dong-xxxxx-firebase-adminsdk-xxxxx.json` دانلود می‌شود. ✅ **فایل ۲**
   🔒 این فایل مثل رمز عبور است؛ جایی نفرست و در گروه نگذار.

### B4) دادن فایل ۲ به سرور (۱ دقیقه)
ساده‌ترین راه (بدون برنامهٔ اضافه):
1. فایل ۲ را با Notepad باز کن → **Ctrl+A**، **Ctrl+C**.
2. در پنجرهٔ سرور بنویس: `nano /root/sa.json` و Enter.
3. **راست‌کلیک** (پیست می‌شود) → **Ctrl+O** → **Enter** → **Ctrl+X**.
4. حالا:
   ```bash
   dong-firebase /root/sa.json
   ```
   باید بنویسد: `✔ نوتیفیکیشن اندروید فعال شد`

(اگر WinSCP/FileZilla بلدی، فایل را به `/root/sa.json` بکش و همان دستور را بزن.)

## بخش C — GitHub: ساخت اپ اندروید با نوتیفیکیشن

1. فایل ۱ (`google-services.json`) را با Notepad باز کن → **Ctrl+A**، **Ctrl+C**.
2. برو به **<https://github.com/soheilxcoder/dong/settings/secrets/actions>**
   (یا: صفحهٔ ریپو → **Settings** → منوی چپ **Secrets and variables** → **Actions**)
3. **New repository secret**
   - **Name:** `GOOGLE_SERVICES_JSON`
   - **Secret:** پیست کن (Ctrl+V)
   - **Add secret**
4. برو به تب **Actions** → منوی چپ **Android APK** → دکمهٔ **Run workflow** → **Run workflow** (سبز).
5. ۵ دقیقه صبر کن → **Releases** → `apk-latest` → در متن باید ببینی: **نوتیفیکیشن: فعال (Firebase)** → `dong-latest.apk` را دانلود کن و روی گوشی‌ها نصب کن (نسخهٔ قبلی را حذف لازم نیست؛ روی همان نصب می‌شود).

---

## تست نهایی (۲ دقیقه، با ۲ گوشی)

1. در هر دو گوشی اپ را باز کن → **پروفایل ← اتصال به سرور** → بنویس: `https://دامنه/api` → ذخیره.
2. هر کدام ثبت‌نام کن. اپ یک بار اجازهٔ نوتیفیکیشن می‌خواهد → **Allow**.
3. گوشی ۱: گروه بساز → لینک دعوت را برای گوشی ۲ بفرست → گوشی ۲ عضو شود.
4. گوشی ۱: یک هزینه ثبت کن و **اپ گوشی ۲ را ببند**.
5. روی گوشی ۲ باید نوتیف بیاید: **«هزینه جدید در دُنگ»** 🎉 لمسش کن → مستقیم همان گروه باز می‌شود.

## اگر چیزی درست نبود

| علامت | چه کنم |
|---|---|
| نوتیف نمی‌آید ولی همه‌چیز دیگر کار می‌کند | روی سرور: `journalctl -u dong -n 50` — اگر `FCM push enabled` نیست، بخش B4 را دوباره انجام بده. اگر خطای `403`/`PERMISSION_DENIED` می‌بینی، سرور داخل ایران است (بالا را بخوان). |
| در ریلیز نوشته «نوتیفیکیشن: غیرفعال» | Secret با نام دقیق `GOOGLE_SERVICES_JSON` ساخته نشده یا خالی است. |
| اپ اجازهٔ نوتیف نپرسید | پروفایل → کلید «نوتیفیکیشن» را روشن کن؛ یا تنظیمات اندروید → اپ دُنگ → Notifications → Allow. |
| گوشی هواوی بدون Google | FCM ندارد؛ نوتیف نمی‌آید، بقیهٔ اپ کار می‌کند. |
| `https` باز نمی‌شود | رکورد A دامنه هنوز فعال نشده؛ ۳۰ دقیقه بعد روی سرور: `certbot --nginx -d دامنه` |
| به‌روزرسانی به نسخهٔ جدید | روی سرور: `dong-update` |
| بازگردانی بک‌آپ | فایل‌های `/root/dong-backups/*.tgz` را در `/var/lib/dong` باز کن و `systemctl restart dong` |
